# RoundsPlugin — Мини-игра ROUNDS в Minecraft

> **Язык:** Русский · [English](readme.en.md)

**RoundsPlugin** — это соревновательный 2D/3D шутер-платформер прямо на вашем сервере Minecraft, вдохновлённый популярной игрой **ROUNDS**!

Здесь нет скучного закликивания мечами: игроки получают скорострельные пушки со щитами, сражаются раунд за раундом, а проигравшие выбирают безумные карты улучшений (рикошеты, вампиризм, яд, пилы, призыв фантомов, бурение сквозь стены и многое другое).

Плагин полностью автономен, настраивается за 2 минуты с помощью расстановки физических блоков прямо в игре и снабжен **умными ИИ-ботами**, с которыми можно полноценно играть даже в одиночку!

---

## Главные фишки плагина

- **Командные перестрелки (до 4 команд):** Синие, Красные, Жёлтые и Зелёные + удобный режим наблюдения для зрителей.
- **Кастомное оружие (Пушка):**
  - **ЛКМ:** Стрельба пулями с физикой полёта, рикошетами от стен и карточными эффектами.
  - **ПКМ:** Блок щитом (парирует пули, активирует защитные вспышки, ударные волны и контрудары).
  - **Q (Клавиша выброса):** Ручная перезарядка обоймы с наглядным прогресс-баром в Action Bar.
- **112 уникальных карточек:**
  - Огромная база готовых способностей: ядовитые облака, заморозка, вампиризм, самонаведение пуль, цепные молнии, пила вокруг игрока при блоке, притягивание врагов, распил в упор, прыжки через стены и спасение от смерти.
  - 5 уровней редкости: `COMMON`, `UNCOMMON`, `RARE`, `EPIC`, `LEGENDARY`.
  - **Система камбэков:** проигравшая раунд команда получает право выбрать новую карту перед следующим боем. Чем больше проигрываешь — тем сильнее становишься!
  - Удобный инвентарь карт для игроков (`/rdebug cards show`) и редактор для администраторов.
- **Умные боты (NMS Fake Players):**
  - Не глупые зомби, а полноценные фальшивые игроки с честной физикой и 10 уровнями сложности.
  - Умеют стрейфить, отступать за укрытия, лечиться щитом, устраивать засады за углом коридора, прыгать по батутам, подниматься на лифтах и грамотно драфтить карты.
  - Массовый спавн до 500 ботов без лагов сервера (FPS/TPS оптимизирован через матрицу характеристик и NavMesh).
  - Автоматически видят, какие команды вы поставили на карте, и балансируются только в них!
- **Крутые фишки для зрителей:**
  - Наблюдатели видят контуры всех живых бойцов, подсвеченные цветом их команд (через стены).
  - При этом сами выживающие бойцы подсветку не видят — стелс, невидимость и маскировка в укрытиях работают честно!
  - В конце раунда зрителям выводятся аккуратные титры в цвете победившей команды.
- **Настройка арены за 2 минуты:** Никаких мучений с координатами в конфигах — просто возьмите спец-блоки через `/rdebug giveblocks` и расставьте их в мире.
- **Полная совместимость:** Работает на Paper / Purpur 1.20.4+ (вплоть до 1.21.x / 26.2), поддерживает TAB, PlaceholderAPI и локализацию интерфейса на лету.

## Быстрый старт: как запустить игру за 2 минуты

Вам не нужно вручную прописывать координаты углов арены в конфигурационных файлах. Всё настраивается прямо из инвентаря:

### Шаг 1. Получите блоки строителя
Зайдите на сервер с правами оператора (или правом `rounds.admin`) и напишите команду:
```
/rdebug giveblocks
```
Вам выдадут стаки всех необходимых блоков, а ваш режим автоматически переключится в **Creative**.

### Шаг 2. Оформите лобби
1. Поставьте **Блок лобби** (Изумрудный блок / Маяк) в месте, куда должны возвращаться игроки после матча.
2. Поставьте цветные блоки шерсти на полу:
   - **Светло-синяя шерсть** — вход за синих.
   - **Красная шерсть** — вход за красных.
   - **Жёлтая шерсть** — вход за жёлтых.
   - **Лаймовая шерсть** — вход за зелёных.
   - **Белая шерсть** — выход в зрители.
   > *Совет:* Если вы строите дуэльную арену 1v1, поставьте только красную и синюю шерсть — плагин и боты поймут, что других команд в этой игре нет!

### Шаг 3. Разметьте боевую зону (Арену)
1. В центре боевой площадки поставьте **Блок зоны карты** (Алмазный блок для зоны 50x50 или Изумрудный для 100x100).
2. Внутри этой зоны расставьте **Блоки спавна** (Обсидиан) — в них плагин будет раскидывать команды при старте раунда.
3. По желанию добавьте интерактивности:
   - **Угольный блок** — батут (отнимает 20% здоровья и подбрасывает высоко вверх).
   - **Глазурованная керамика / призмарин** — лифт (плавно поднимает на верхние ярусы).

### Шаг 4. В бой!
Наступите на шерсть своей команды и начните игру:
- Наступите на **Железный блок** (Блок старта) ИЛИ введите команду:
```
/rdebug start
```
Плагин запустит отсчет, откроет меню выбора карт и перенесет бойцов на арену!

| Блок в игре | Предмет / Материал | Что он делает? |
| :--- | :--- | :--- |
| **Выбор команды** | Цветная шерсть (`LIGHT_BLUE`, `RED`, `YELLOW`, `LIME_WOOL`) | Игрок или бот наступает на блок и мгновенно вступает в команду. |
| **Зритель** | Белая шерсть (`WHITE_WOOL`) | Выход из команд в режим наблюдателя. |

| **Зона карты 50x50** | Алмазный блок (`DIAMOND_BLOCK`) | Центр боевой площадки 50x50 блоков. Можно поставить несколько — плагин будет чередовать их каждый раунд! |
| **Зона карты 100x100** | Изумрудный блок (`EMERALD_BLOCK`) | Центр большой площадки 100x100 блоков. |
| **Точка спавна** | Обсидиан (`OBSIDIAN`) | Место появления команды на арене. Ставьте внутри радиуса зоны карты. |
| **Батут (Jump Pad)** | Угольный блок (`COAL_BLOCK`) | Наносит 20% урона и запускает игрока высоко в воздух. |
| **Лифт (Up-Block)** | Пурпурная керамика / Призмарин | Столб вертикального подъема на верхние этажи арены. |
| **Кнопка СТАРТ** | Железный блок (`IRON_BLOCK`) | Запуск матча при наступании. |
| **Кнопка СТОП** | Блок красного камня (`REDSTONE_BLOCK`) | Принудительная остановка матча и возврат всех в лобби. |

## Умные боты (NMS Fake Players)

В плагин встроена собственная система боевых ИИ-ботов. Они создаются сервером как настоящие игроки (ServerPlayer), отображаются в Tab, скорбордах и прицелах, и подчиняются честным правилам игры:

- **10 уровней сложности:** Уровень от 1 до 10 случайным образом выдается боту каждый раунд. На 1 уровне бот медленный и промахивается, на 10 — фликает прицелом как киберспортсмен, стреляет на упреждение и идеально парирует щитом.
- **4 стиля игры:** Бот может играть как агрессивный фланкер с баннихопом, осторожный снайпер на дистанции 20м, глухая черепаха со щитом или бешеный броулер ближнего боя.
- **Честное зрение:** Боты не видят сквозь стены (Line-of-Sight), имеют угол обзора 140° и слышат шаги за спиной только ближе 2.5 метров.
- **Тактические засады:** Скрывшись за угол, бот не упирается лицом в стену, а держит прицел на открытый угол коридора, заряжает щит бонусом карты `Empower` и делает моментальный выстрел при появлении цели.
- **Паркур и реакция на карты:** Если бот взял карточки на высокий прыжок, он понимает свои новые габариты и легко перепрыгивает препятствия в 2 и 3 блока, прыгает через пропасти и уверенно поднимается на лифтах.
- **Пила в упор:** Если бот взял карту «Пила», при поднятии щита он агрессивно рашит противника на скорости бега вплотную (<2.8м), превращая его в фарш огненным кольцом.
- **Поддержка карты:** Боты автоматически определяют, спавны каких команд стоят на карте, и заходят только за них.

### Команды управления ботами:
```bash
# Заспавнить одного бота (имя и команда выберутся автоматически)
/rbot spawn

# Заспавнить сразу 10 ботов со сбалансированными командами
/rbot spawn count 10

# Заспавнить конкретного бота (например, крутого снайпера 10 уровня за синих)
/rbot spawn SniperBot BLUE 10

# Удалить всех ботов с арены
/rbot despawn all

# Посмотреть список ботов, их здоровье и уровень интеллекта
/rbot list
```
*(Все боты также автоматически и без следа удаляются при завершении игры или команде `/rdebug stop`)*

## Карточная система и способности

После каждого раунда проигравшие игроки получают интерактивное меню из 5 случайных карт.

### Популярные примеры карт и комбо:
- **Пила (Saw):** При блокировании щитом вокруг вас крутится огненное кольцо, наносящее чудовищный урон вблизи.
- **Коллапс (Implode):** При поднятии щита все враги поблизости притягиваются прямо к вам под выстрел.
- **Сайленс (Silence):** Блок щитом глушит оружие и способности врагов вокруг на несколько секунд.
- **ЭМП (EMP):** Замедляет и парализует противников в радиусе действия.
- drill **Буровые патроны (Drill):** Ваши пули прошивают стены и блоки насквозь.
- **Вампиризм (Leech) и Аура вампиризма:** Лечитесь от нанесённого врагам урона.
- **Палач (Executioner):** Мгновенно добивает врагов с низким запасом здоровья.
- **Бездна (Abyssal):** Если постоять на месте 10 секунд — призывает боевого фантома.
- **Empower:** Заряжает следующий выстрел сокрушительным бонусным уроном, если перед стрельбой поднять щит.

*(Всего в плагине 112 встроенных карт в папке `plugins/RoundsPlugin/cards/original/`. Вы можете легко менять их параметры или создавать свои собственные карты в папке `custom/`!)*

## Основные команды плагина

Основная административная команда — `/rdebug`. Для управления ботами есть короткая команда `/rbot`.

### Для игроков:
| Команда | Что делает? |
| :--- | :--- |
| `/rdebug join` | Войти в игру (автоматически выберет команду с наименьшим числом игроков). |
| `/rdebug cards show [игрок]` | Посмотреть собранную колоду карт (свою или другого игрока). |
| `/rdebug stats [игрок]` | Посмотреть боевые характеристики (урон, скорость, ХП, патроны). |
| `/rdebug info` | Информация о текущем матче и состоянии арены. |

### Для администраторов (`rounds.admin` или OP):
| Команда | Что делает? |
| :--- | :--- |
| `/rdebug start` | Запустить игру на арене. |
| `/rdebug stop` | Принудительно остановить матч, удалить ботов и вернуть всех в лобби. |
| `/rdebug giveblocks` | Выдать стак всех специальных блоков арены и включить креатив. |
| `/rdebug setlobby` | Установить точку лобби прямо на месте, где вы стоите. |
| `/rdebug rounds <число>` | Задать количество побед для общего выигрыша в матче (по умолчанию 5). |
| `/rdebug cardchoicetime <сек>` | Время на выбор карты (от 10 сек, по умолчанию 30). Звуковой отсчёт XP на последних 5 сек, наковальня на 1 сек и кик при тайм-ауте. |
| `/rdebug freeplay <on\|off>` | Включить режим свободного доступа (игроки смогут сами писать `/rdebug start`). |
| `/rdebug autodeath <on\|off>` | Включить автоубийство случайного игрока при затянувшемся раунде (> 4 мин). |
| `/rdebug cards add <игрок> <id>` | Выдать конкретную карточку игроку или боту. |
| `/rdebug givegun [игрок\|@a]` | Выдать пушку себе или всем игрокам. |
| `/rdebug resetstats [игрок]` | Сбросить полученные карты, улучшения и ХП до стандартов. |
| `/rdebug setlanguage <RU_ru\|EN_en>` | Сменить язык плагина на лету прямо из игры. |
| `/rdebug reload` | Перезагрузить конфиг `config.yml` и все файлы карт без рестарта сервера. |

## Настройка `config.yml` (Шпаргалка)

```yaml
# Язык сообщений из папки lang/ (RU_ru, EN_en и др.)
language: RU_ru

# Начальные характеристики бойцов в 1-м раунде
defaults:
  hp: 20                 # Здоровье (20 = 10 сердечек)
  damage: 3.0            # Урон одной пули
  ammo: 3                # Патронов в обойме
  max-ammo: 3            # Максимальный размер обоймы
  attack-speed: 20       # Кулдаун между выстрелами в тиках (20 тиков = 1 сек)
  bullet-speed: 1.0      # Скорость полета пули

# Параметры игры
game:
  default-rounds: 5      # Сколько раундов нужно выиграть для победы в матче
  max-rounds: 20         # Максимальный лимит раундов
  card-selection-time: 200 # Время на драфт карты (200 тиков = 10 секунд)

# Автоматические правила мира во время матча (не ломает спавн мобов в других мирах!)
game-rules:
  enabled: true
  instant-respawn: true       # Мгновенный респавн без экрана смерти
  keep-inventory: true        # Сохранение инвентаря
  freeze-time: true           # Вечный день на арене
  disable-weather: true       # Без дождя и грозы
  disable-mob-spawning: true  # Блокировка спавна мобов на арене

# Настройка батутов
jump-block:
  damage-percent: 20.0   # Сколько % HP отнимает батут при прыжке
  launch-height: 10.0    # Высота полета
```

## Плейсхолдеры для TAB и Scoreboard (PlaceholderAPI)

Плагин полностью поддерживает PlaceholderAPI. Идентификатор: `%rounds_...%`

- `%rounds_round%` — номер текущего раунда.
- `%rounds_rounds_to_win%` — сколько раундов нужно для победы.
- `%rounds_round_display%` — красивый счёт (например, `3/5`).
- `%rounds_state%` — состояние матча (`WAITING`, `CARDS`, `PLAYING`, `ROUND_END`, `GAME_END`).
- `%rounds_team%` — название команды игрока (Синие, Красные...).
- `%rounds_team_color%` — цвет команды игрока (`§9`, `§c`, `§e`, `§a`).
- `%rounds_blue_wins%`, `%rounds_red_wins%`, `%rounds_yellow_wins%`, `%rounds_green_wins%` — победы каждой команды.
- `%rounds_stat_hp%`, `%rounds_stat_dmg%`, `%rounds_stat_ammo%` — текущие характеристики игрока с учетом всех карт.
- `%rounds_stat_cards%` — общее число собранных карточек.

## Системные требования и установка

1. **Сервер:** Paper, Purpur или форки 1.20.4+ (гарантированная работа на 1.20.x — 1.21.x+).
2. **Java:** Java 17 или новее.
3. Скачайте `RoundsPlugin.jar`, закиньте в папку `plugins/` и перезапустите сервер.
4. Наслаждайтесь игрой!
