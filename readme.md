# RoundsPlugin v1.0

Minecraft плагин мини-игры "Rounds" (Raunds). 4 команды, карточная система со 65 картами, стрельба, до 20 раундов, система блоков карты для спавна, настраиваемые правила мира.

---

## Требования

- Paper 1.20.4 - 26.2+
- Java 17+
- Опционально: [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.13006/) для поддержки плейсхолдеров
- Опционально: [TAB](https://www.spigotmc.org/resources/tab.57806/) для отображения счёта и статуса игры

---

## Установка

1. Скопируйте `RoundsPlugin-1.0.jar` в папку `plugins/`
2. Перезапустите сервер
3. Настройте `plugins/RoundsPlugin/config.yml` (по умолчанию уже настроено)
4. Настройте карты в `plugins/RoundsPlugin/cards/` (по умолчанию 65 карт)
5. Получите блоки командой `/rdebug giveblocks` и расставьте в мире

## Быстрый старт

### 1. Получите блоки

Администратор должен получить командой:

```
/rdebug giveblocks
```

Это выдаст все специальные блоки в инвентарь и переключит в режим выживания. Разместите блоки в мире:

#### Блоки вступления в команды

| Блок | Материал | Что делает |
|------|----------|-----------|
| **Синий вход** | Синяя шерсть | Вступить в синюю команду |
| **Красный вход** | Красная шерсть | Вступить в красную команду |
| **Жёлтый вход** | Жёлтая шерсть | Вступить в жёлтую команду |
| **Зелёный вход** | Зелёная шерсть | Вступить в зелёную команду |

#### Блоки карты и спавна

| Блок | Материал | Что делает |
|------|----------|-----------|
| **Блок лобби** | Изумрудный блок | Центр лобби. Только 1 блок. При старте все телепортируются сюда. Если поставить второй — второй становится основным |
| **Блок карты 50x50** | Алмазный блок | Центр зоны карты 50x50 блоков. Спавны ищутся внутри этой зоны |
| **Блок карты 100x100** | Изумрудный блок | Центр зоны карты 100x100 блоков |
| **Блок спавна** | Бикон | Точка спавна для команды внутри зоны карты |

#### Блок управления

| Блок | Материал | Что делает |
|------|----------|-----------|
| **Тэгщитов CD** | Железный блок | Начать игру (только для `rounds.admin`) |

### 2. Расставьте блоки карты

1. Поставьте **блок лобби** — центр вашей зоны лобби
2. Поставьте **блоки карты** (50x50 или 100x100) — центры зон, на которых будет идти игра
3. Внутри зоны каждого блока карты поставьте **блоки спавна** — точки, где будут появляться команды
4. Может быть несколько блоков карты — в каждом раунде плагин выберет случайную зону

### 3. Игроки вступают в команды

Игроки просто **наступают** на цветной блок шерсти, чтобы вступить в команду.
Менять команду можно до начала игры (просто наступить на другой блок).
Кулдаун смены команды — 1 секунда.

### 4. Запустите игру

```
/rdebug start
```

Или наступите на блок **Тэгщитов CD** (железный блок) в мире.

### 5. Как проходит игра

1. Все игроки телепортируются на **блок лобби** (+1 по высоте)
2. В чате идёт **таймер 5 → 1** (секунды)
3. На каждом тике все игроки становятся **спектаторами** и телепортируются на случайный блок спавна для превью
4. После таймера каждая команда телепортируется на **свой блок спавна** (+1 по высоте), игроки получают **режим выживания** и пушку
5. Открывается **выбор карт** — каждый игрок выбирает 1 карту из 5
6. Начинается раунд — игроки стреляют друг в друга
7. Последний выживший в раунде побеждает
8. **Следующий раунд** — плагин выбирает **случайную зону карты** (с повторами), распределяет спавны заново, все телепортируются
9. Когда команда набирает нужное количество побед — **конец игры**, всех телепортирует в лобби

## Настройка

### config.yml

```yaml
# Язык: "ru" или "en"
language: ru

# Статы игроков по умолчанию (сбрасываются каждый раунд)
defaults:
  damage: 3.0            # Базовый урон за пулю
  attack-speed: 20       # Кулдаун атаки в тиках (20 = 1 сек)
  ammo: 3                # Текущие патроны
  max-ammo: 3            # Максимум патронов
  bullets: 1             # Количество пуль за выстрел
  hp: 20                 # Здоровье
  bullet-speed: 1.0      # Скорость пуль
  reload-speed: 0        # Скорость перезарядки (0 = базовая 3 сек)

game:
  default-rounds: 5      # Раундов для победы по умолчанию
  max-rounds: 20          # Максимум раундов
  card-selection-time: 200 # Время выбора карт (200 тиков = 10 сек)
  respawn-delay: 5        # Задержка респавна

teams:
  enabled:
    - BLUE
    - RED
    - YELLOW
    - GREEN

gun:
  material: STICK           # Материал пушки
  base-cooldown: 20         # Базовый кулдаун

cards:
  selection-count: 5        # Количество карт для выбора
  weighted-rarity: true     # Взвешенный выбор по редкости

# Правила мира (автоматически применяются во время игры)
game-rules:
  enabled: true             # Глобальный переключатель
  instant-respawn: true     # Мгновенный респавн (без экрана смерти)
  keep-inventory: true      # Сохранение вещей при смерти
  freeze-time: true         # Заморозка времени (всегда день)
  disable-weather: true     # Отключение смены погоды
  disable-mob-spawning: true # Отключение спавна мобов

# Окраска ников в цвет команды
color-nicknames: true

# Встроенный scoreboard (отключён по умолчанию, конфликтует с TAB)
builtin-scoreboard:
  enabled: false
  title: "&6&lROUNDS"
```

#### Колесо карт (Wheel)

Администратор может включить автоматическую ротацию карт во время выбора:

```
/rdebug wheel on
```

Каждые 6 секунд все открытые GUI выбора карт обновляются новыми случайными картами.

## Система блоков карты

### Блоки карты

Блоки карты определяют зоны на карте. Зона — это куб: `[centerX ± size/2, centerZ ± size/2]`, Y от -64 до 320.

- Может быть **несколько** блоков карты на разных частях карты
- В каждом раунде плагин **случайно выбирает** одну из зон (с возможностью повтора)
- Внутри зоны ищутся все **блоки спавна**

### Блоки спавна

Блоки спавна определяют точки, где появляются команды:

- При начале раунда плагин находит все блоки спавна внутри выбранной зоны карты
- Команде A выдаётся **случайный** блок спавна
- Команде B — **случайный** из оставшихся
- Если спавнов меньше чем команд — спавны переиспользуются

### Блок лобби

- Один блок на карте, обозначает центр лобби
- Если поставить второй — второй становится основным
- При `/rdebug start` все игроки телепортируются на лобби (+1Y)
- При **конце игры** все игроки возвращаются в лобби

## Команды

Все команды управления игрой собраны в `/rdebug`.

### Управление игрой

| Подкоманда | Аргументы | Описание |
|-----------|-----------|----------|
| `/rdebug start` | | Начать игру (телепорт в лобби → таймер → распределение по спавнам) |
| `/rdebug stop` | | Остановить игру и сбросить всё |
| `/rdebug status` | | Показать состояние игры |
| `/rdebug rounds <число>` | | Установить раундов для победы (1-20) |
| `/rdebug info` | | Информация о плагине |
| `/rdebug join` | | Присоединиться к команде во время игры |
| `/rdebug test` | | Проверка — "RoundsPlugin работает!" |

### Блоки карты

| Подкоманда | Аргументы | Описание |
|-----------|-----------|----------|
| `/rdebug giveblocks [игрок]` | | Выдать все специальные блоки (команды, лобби, карты, спавны) |

### Карты

| Подкоманда | Аргументы | Описание |
|-----------|-----------|----------|
| `/rdebug cards` | | Открыть GUI выбора карт |
| `/rdebug cards reload` | | Перезагрузить карты из файлов |
| `/rdebug cards test [id]` | `[id]` | Применить карту по ID или открыть GUI |
| `/rdebug cards giveall` | | Разблокировать все карты |
| `/rdebug applycard <имя>` | | Применить карту по имени |

### Предметы

| Подкоманда | Аргументы | Описание |
|-----------|-----------|----------|
| `/rdebug givegun [игрок\|@a]` | | Выдать пушку себе, игроку или всем |
| `/rdebug giveall` | | Выдать все карты |
| `/rdebug wheel on\|off` | | Включить/выключить ротацию карт |

### Scoreboard

| Подкоманда | Аргументы | Описание |
|-----------|-----------|----------|
| `/rdebug tab on\|off` | | Включить/выключить встроенный scoreboard |
| `/rdebug tab name <заголовок>` | | Изменить заголовок scoreboard |

Встроенный scoreboard показывает: текущий раунд, команду игрока и победы всех активных команд (только команды с игроками).

### Отладка

| Подкоманда | Аргументы | Описание |
|-----------|-----------|----------|
| `/rdebug help` | | Справка по всем подкомандам |
| `/rdebug stats [игрок]` | | Показать все статы игрока |

## Интеграция с TAB

В папке `TAB/` находится готовый конфигурационный файл для плагина TAB. Он показывает:

- Счёт команд в сайдбаре (только во время игры)
- Отображение раунда и прогресса
- Индикация команды игрока с цветом
- Настройка tablist, nametag и header/footer

---

## Сохранение состояния

Плагин автоматически сохраняет:

- **Состояние игры** (`game-state.yml`) — номер раунда, победы команд, погибшие игроки
- **Данные игроков** — статы, карты, команда (через PersistentDataContainer + `active-players.yml`)
- **Блоки карты** (`rounds-map-blocks.yml`) — позиции блоков лобби, карт и спавнов

При перезапуске сервера во время активной игры состояние восстанавливается автоматически.

## Локализация

Плагин поддерживает **русский** и **английский** языки. Для смены:

1. Откройте `plugins/RoundsPlugin/config.yml`
2. Измените `language: ru` на `language: en`
3. Перезапустите сервер

Все тексты хранятся в `plugins/RoundsPlugin/messages.yml`. Чтобы добавить свой язык — скопируйте секцию `ru:` или `en:` и замените тексты.

Карты поддерживают локализацию в формате `name.ru` / `name.en` и `description.ru` / `description.en`.
